# setup: はじめての準備

AIにあまり詳しくない人向けの初期設定。相手は専門用語を知らない前提で話す。

**話し方**

- 1回に伝えることは少なくする。
- 「API」「ターミナル」「パス」などの言葉は使わない。どうしても必要なら、一言で言い換える(例: APIキー = 「サービスを使うための合言葉」)。
- 進んでいることが分かるように、「準備 2/5: 部品を入れます」のように段階を示す。
- 選んでもらうときは AskUserQuestion を使う。

スクリプト: `doctor` = `python3 "${CLAUDE_SKILL_DIR}/scripts/doctor.py"`(作業フォルダで実行する)

## 1/5 あいさつと作業フォルダ

まず3行で説明する。

> このツールでは、作りたい動画を話しかけるだけで、絵コンテ(動画の設計図)を作り、仮の音声付きで再生して確認し、最後にAIで動画にできます。
> これから5分ほどで準備をします。お金がかかる操作は、必ず先に確認します。

次に、今開いているフォルダが作業に向いているか確認する(`pwd` と `ls` で見る)。

- 次のどれかなら、専用のフォルダを作る。
  - ホームフォルダそのもの
  - デスクトップ
  - 関係ないファイルがたくさんあるフォルダ
- 作り方:
  1. AskUserQuestion で「動画用のフォルダ『ムービー/AI動画』を作ってよいか」を聞く。
  2. OKなら `mkdir -p ~/Movies/AI動画` を実行する。
  3. 「Claudeの画面でそのフォルダを開き直して、もう一度 /ai-video:setup と入力してください」と伝え、開き方も案内する。案内: 画面上部のフォルダ名をクリック → 「ムービー」の中の「AI動画」を選ぶ。ここで終了する。
- すでに空のフォルダ、または `projects/` があるフォルダなら、そのまま進む。

## 2/5 パソコンの確認

`doctor check` を実行し、結果を次のような表にして見せる。技術的な詳細は省く。

| 項目 | 状態 |
| --- | --- |
| 動画の部品(ffmpeg) | 入っている / これから入れる |
| 日本語の読み上げ | 使える / 設定が必要 |
| 作業フォルダ | 準備済み / これから作る |
| サービスの合言葉(APIキー) | 設定済みのもの |

足りないものがあれば、この順で対処する。

- **Mac ではない**: 「このツールはMac専用です」と伝えて終了する。
- **Python がない**: 「パソコンが『デベロッパツールをインストールしますか』と聞いてきたら『インストール』を押してください。終わったら『できた』と教えてください」と伝える。終わったら、もう一度 check を実行する。
- **ffmpeg がない**:
  1. AskUserQuestion で確認する。伝える内容は次の4点。
     - 動画を作るための部品を入れること
     - 約60MBのダウンロード
     - 入手先は ffmpeg.martin-riedl.de(署名済みで、中身が正しいか自動で確認する)
     - このツール専用の場所に置き、パソコンの設定は変えないこと
  2. OKなら `doctor install-ffmpeg` を実行する。
- **日本語の声(Kyoko)がない**: 「システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 声を管理 → 日本語の Kyoko を追加」と案内する。なくても進めてよい(仮の音声だけが使えない)。

## 3/5 作業フォルダの準備

`doctor workspace` を実行する。作られるものを一言ずつ説明する。

- `projects` フォルダ: 作った動画プロジェクトの置き場所
- `.env.local`: 合言葉(APIキー)を書くメモ

## 4/5 合言葉(APIキー)の設定

まず、何をしたいかを AskUserQuestion(複数選択)で聞く。

| 選択肢 | 必要な合言葉 | 費用の目安 |
| --- | --- | --- |
| まずは無料で試したい | なし(絵コンテと仮音声の再生まで) | 0円 |
| 絵コンテの画像をきれいに作りたい | OpenAI | 1枚 約1〜6円 |
| 動画を作りたい(おすすめ: Kling) | Kling | 5秒 約65〜95円 |
| 動画を作りたい(Seedance) | BytePlus | 5秒 約60〜180円 |

費用は1ドル150円で計算した目安だと添える。「無料で試したい」だけなら、このステップを飛ばして5へ進む。

選ばれたサービスごとに、順番に案内する。1つずつ、終わってから次へ進む。

1. **合言葉を作るページを開く**。`open <URL>` で開いてよいか聞いてから開く。
   - OpenAI: https://platform.openai.com/api-keys(先に支払い方法の登録が必要。画像を使うには、組織の本人確認を求められることがある)
   - Kling: https://kling.ai/dev/api-key(先にチャージが必要)
   - BytePlus: https://console.byteplus.com/ark/region:ark+ap-southeast-1/apiKey(Seedance 2.0 以降は残高 USD 30 以上などの条件がある)
   - Gemini: https://aistudio.google.com/apikey
2. **ページでの操作を伝える**: 「作成」ボタンを押し、表示された合言葉を「コピー」してください。合言葉は一度しか表示されないことが多いので、閉じる前にコピーしてください。
3. **メモに貼り付けてもらう**: `open -e .env.local` でテキストエディットを開き、次のように伝える。
   > 該当する行(例: `OPENAI_API_KEY=`)の `=` のすぐ右に貼り付けて、⌘S で保存し、閉じてください。終わったら「できた」と教えてください。
4. **合言葉はチャットに貼らないよう伝える**。もし貼られてしまっても、画面に繰り返し表示しない。その場合は、ユーザーの了承を得て `.env.local` の該当行に書き込み、「念のため、あとで同じページで作り直すと安心です」と伝える。
5. 全部終わったら `doctor keys` を実行し、結果を説明する。
   - 「使えます」→ 次へ進む。
   - 「キーが正しくない」→ 貼り付け直しを案内する(前後に空白や改行が入っていないか確認してもらう)。

## 5/5 サンプルで試す

AskUserQuestion で「サンプルの絵コンテを見てみますか(無料)」と聞く。OKなら次を実行する。

1. `doctor demo` を実行する。projects/sample ができる(3カット・画像なし)。
2. `python3 "${CLAUDE_SKILL_DIR}/../storyboard/scripts/sb.py" animatic sample` を実行する。仮の音声つきの10秒の動画ができ、動画プレーヤーで開く。
   - 「灰色の画面は、まだ画像がないカットです。声はパソコンの読み上げです」と伝える。
3. `python3 "${CLAUDE_SKILL_DIR}/../storyboard/scripts/sb.py" render sample` を実行し、出力の `file_path`・`files`・`description` で Artifact を公開する(初回は `icon: "film"`)。そのあと `sb.py set-url sample <URL>` を実行する。
   - 「これが絵コンテのページです。カットごとの画像・カメラ・音が並び、上でアニマティックも見られます」とリンクを伝える。
   - Artifact ツールがないときは `sb.py render sample --open` で開く。

## 最後に: 使い方の早見表

次の表を見せて終わる。

| やりたいこと | 話しかけ方の例 |
| --- | --- |
| 動画の設計図(絵コンテ)を作る | 「15秒の〇〇の動画の絵コンテを作りたい」 |
| 参考動画をまねる | 「この動画みたいにしたい」+ 動画ファイルをドラッグ |
| 仮の音声付きで再生する | 「アニマティックで再生して」(動画プレーヤーで開きます) |
| 画像の一部を直す | 「c02 の右上に気球を足して」のように、直したい場所と内容を言う |
| 動画にする | 「プロンプトにして Kling で生成して」(費用は事前に確認します) |
| 生成した動画を直す | 「s02 の笑顔が硬いので直して」 |
| 準備をやり直す・調子が悪い | 「/ai-video:setup」 |

困ったときは「うまくいかない」と話しかければよい、と一言添える。

最後に AskUserQuestion で「続けて、10秒の動画を1本作ってみますか(15分ほど)」と聞く。作る → tutorial スキルを始める。あとで → 「いつでも /ai-video:tutorial で始められます」と伝えて終える。
